## ⚙️ CMake 构建流程

### 步骤 1️⃣：配置阶段

**操作：** 创建构建目录并生成 Makefile

```bash
mkdir build && cd build
cmake ..
```

**CMake 执行的操作：**
- ✅ 设置 C11 标准
- ✅ 添加头文件搜索路径：`src/include`
- ✅ 生成 Makefile

---

### 步骤 2️⃣：编译阶段

**操作：** 编译所有源文件并链接成可执行文件

```bash
make
```

**编译过程：**
```
src/main.c ───────────────────┐
src/app/*.c ──────────────────┤
src/core/student_list.c ──────┤
src/core/student.c ───────────┼──► 编译器 ──► for_review.exe
src/core/command.c ───────────┤
src/core/file_manager.c ──────┤
src/utils/*.c ────────────────┘
```

---

### 步骤 3️⃣：运行程序

**操作：** 执行生成的可执行文件

```bash
./for_review
```

## ❗
## 📦 模块详细说明

### 1️⃣ 应用层 (app/)

负责用户界面和交互逻辑

- **app_window.c/h** - 主窗口管理
  - 创建和管理主窗口
  - 处理窗口事件
  
- **file_browser.c/h** - 文件浏览界面
  - 文件选择功能
  - 文件列表显示
  
- **student_editor.c/h** - 学生信息编辑界面
  - 添加/修改学生信息
  - 表单验证
  
- **settings.c/h** - 设置界面
  - 系统配置管理
  - 用户偏好设置

---

### 2️⃣ 核心业务层 (core/)

负责数据处理和核心业务逻辑

- **student.c/h** - 学生数据结构与操作
  - 学生信息定义
  - 基本操作方法
  
- **student_list.c/h** - 学生列表管理
  - 链表数据结构
  - 增删改查操作
  
- **file_manager.c/h** - 文件读写操作
  - 数据持久化
  - 文件格式处理
  
- **command.c/h** - 命令模式
  - 支持撤销/重做
  - 命令历史记录

---

### 3️⃣ 工具层 (utils/)

提供通用工具函数

- **config.c/h** - 配置文件管理
  - 读取/写入配置
  - 配置项验证
  
- **validator.c/h** - 数据验证
  - 输入数据校验
  - 格式检查
  
- **thread_pool.c/h** - 简易线程池
  - 异步任务处理
  - 线程管理（预留）
